## First-Commit Findings

- Repository validation and optional local validators passed on the first
  commit.
- Current Codex marketplace add, plugin add, and list succeeded in isolated
  test homes.
- Current Claude root and plugin validation passed after compatibility fields
  were reduced.
- A preinstalled older Claude Code validator rejected optional Claude metadata
  before the compatibility fix. The compatibility shape is guarded by
  repository validation/static manifest checks, optional host validators, and
  observed post-fix validation.
- Codex produced non-blocking PATH-alias warnings when the isolated test home
  was outside the normal profile area.
- A forward status test found that stale or unhealthy sources could be listed
  with `/mcp/stream`, making them look like usable direct MCP endpoints.

## Post-Fix Pass

- Status guidance now allows usable direct MCP Streamable HTTP URLs for
  healthy, client-reachable sources only.
- Stale, unhealthy, registered-only, orphan, duplicate, timed-out, ambiguous,
  and wildcard-host sources may show diagnostic base URLs only and must not
  have `/mcp/stream` appended.
- The repository validator now checks for the healthy-only status guard.
- Public submission drafts and this validation record contain no credentials,
  private endpoints, private local paths, or raw logs.
- The Codex submission ZIP builder creates a deterministic skills-only archive
  named from the plugin version and prints the archive contents for inspection.

## Redaction Rules

- Replace source URLs with `redacted source URL` in public reports.
- Replace local folders, home directories, temporary homes, and workspace paths
  with role descriptions such as `repo root` or `isolated temporary home`.
- Do not include bearer tokens, API keys, cookies, environment dumps, raw logs,
  or wiki source content.
- Keep command summaries at result level unless the exact output is already
  public and contains no local data.
